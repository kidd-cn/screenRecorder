# 画中画与主屏对调（录制中）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 录制中浮条一键对调画面主次——摄像头 contain 放大成主画面、屏幕缩成 160×120 圆角小图，逐帧参数级写进成片；摄像头中途断源走会话级失败自动保存。

**Architecture:** 会话级 `layoutSwapped` 布尔经 `PiPFrameStore` 锁保护快照桥（主线程写 / video 队列读）进 `PiPCompositor.composite` 新增 `layoutSwapped` 参数——同一画布上的布局分支：黑底画布 + 摄像头 contain 主画面 + 屏幕层（含特效）aspect-fill 缩进小图 + 键帽视口锚定。摄像头断源由 `CameraPiPController` 帧新鲜度看门狗检测（fire-once 闩 + 主线程投递，SourceLossMonitor 同型），经装配层接 `CaptureController.handleSessionFailure` 自动保存。对调态浮窗预览切屏幕缩略图（录制器低频节流产 CGImage）。

**Tech Stack:** Swift 5 + ScreenCaptureKit + AVFoundation + CoreImage（既有栈，零新依赖）。

**Spec:** `docs/superpowers/specs/2026-11-08-pip-swap-design.md`（本计划的裁定依据；冲突时以 spec 为准）

## Global Constraints

- macOS 13 底线；零新 TCC 授权；零新依赖。
- **反目标（出现即失败）**：对调不得中断录制、丢帧、writer 重开或 PTS 跳变；摄像头画面绝不裁剪（contain 铁律）；对调后成片分辨率/时间轴与切换前一致。
- 坐标系：捕获像素空间**左上原点、y 向下**（`PiPFrame.rectInCapturePixels` 契约）；CI 画布 y 向上，换算 `ciY = 画布高 − 缓冲 y`（`placePip` 同口径）；本库 CG 全局系同左上原点 y 向下，**不翻 Y**。
- 热路径纪律全继承：单 `CIContext` 复用、`CVPixelBufferPool`、无效果零渲染直通、video 队列串行无锁（对调态逐帧合成恒开是显式用户行为的预期成本，不算违例）。
- 跨线程状态一律锁保护快照（`PiPFrameStore` 同款纪律）：主线程写、video 队列读。
- **禁 `git add -A`**——显式路径 only（仓库根 `build/` 未跟踪陈旧目录绝不能进提交）。
- **本计划零新文件**：全部生产改动落既有源文件、全部测试落既有测试文件——不跑 `xcodegen generate`，不改 `project.yml`。
- UI 文案简体中文；测试全绿零告警；`xcodebuild test` 退出码是唯一权威（SourceKit 诊断是已知噪声，忽略）。
- 测试命令（全程同一条）：`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild test -project ScreenRecorder.xcodeproj -scheme ScreenRecorder -derivedDataPath .build -destination 'platform=macOS'`

`SwappedLayout`（PiPCompositor.swift，`PiPCaptureGeometry` 之后；doc 注释钉 spec §3.2 与「绝不裁剪」铁律）：

```swift
/// 对调布局纯函数（spec §3.2）：摄像头 contain 进画布——缩放比取宽高比**小者**，
/// 居中，余处为黑边（合成侧铺纯黑底）。坐标系：捕获像素空间（左上原点、y 向下）。
enum SwappedLayout {
    /// 非法输入（任一边 ≤ 0 / 非有限）返回 nil = 本帧不合成摄像头主画面。
    /// 取整纪律同 ScreenshotCore 裁剪：origin .rounded(.down)、size .rounded(.up)。
    static func cameraContainRect(canvasSize: CGSize, cameraSize: CGSize) -> CGRect? {
        guard canvasSize.width > 0, canvasSize.height > 0,
              cameraSize.width > 0, cameraSize.height > 0,
              canvasSize.width.isFinite, canvasSize.height.isFinite,
              cameraSize.width.isFinite, cameraSize.height.isFinite else { return nil }
        let scale = min(canvasSize.width / cameraSize.width,
                        canvasSize.height / cameraSize.height)
        let width = (cameraSize.width * scale).rounded(.up)
        let height = (cameraSize.height * scale).rounded(.up)
        let x = ((canvasSize.width - width) / 2).rounded(.down)
        let y = ((canvasSize.height - height) / 2).rounded(.down)
        return CGRect(x: x, y: y, width: width, height: height)
    }
}
```
