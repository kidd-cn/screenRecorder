# ScreenRecorder 二期功能设计文档（对照 OmniRecorder 全功能矩阵）

日期：2026-10-30
状态：范围已批准（用户裁定「全部按优先级排进来」，2026-10-30；优先级排序与本文档内的微决策由本文档代定）
前置：一期已交付并通过全部真机验收（master @ c5d4f85+，274 测试，设计文档 `2026-10-25-screen-recorder-design.md`）

## 1. 意图与背景

一期复刻了 OmniRecorder 的核心录制能力（三模式、双源混音、PiP、点击高亮、暂停、倒计时、快捷键、文件列表、中断保护、退出保护）。二期补齐逆向分析中确认的其余功能矩阵，把应用从「能录」推进到「录出来的东西更有讲师感/会议感」，并覆盖全部录制模式。范围 = 12 项，全部纳入，按本文档排定的优先级分批交付。

## 2. 目标 / 非目标 / 反目标

### 目标（二期，按优先级序）

P1–P9 为交付批次，每批内含若干功能，批次内一起实现、一起验收。

| 批次 | 功能 | 价值 | 工程量 |
|---|---|---|---|
| **P1** | 点击自动缩放 + 点击音效 | 教程向核心：点击处放大引导视线 | 中（共享点击管线） |
| **P2** | 边录边标记（画笔） | 教程向：录制中圈点标注 | 中大 |
| **P3** | App 内容录制 + 窗口区域录制 | 补全 OmniRecorder 7 模式中可做的 2 个 | 中（共享选择器/裁剪管线） |
| **P4** | 键盘按键可视化 | 会议/教程：按键上屏 | 中（需新 TCC，见 §5） |
| **P5** | 摄像头虚拟背景（模糊 + 内置背景） | 会议向：隐私与观感 | 中 |
| **P6** | 开机自启 + 定时录制 | 小工具项捆绑 | 小 |
| **P7** | 声音录制 / 摄像头录制独立模式 | 补全模式矩阵 | 中小 |
| **P8** | GIF 导出 + 转换压缩 | 成片分享 | 中 |
| **P9** | 视频编辑器（缩放分段剪辑导出） | 后期加工；依赖 P1 的缩放变换复用 | 大 |

### 非目标（二期仍不做）

- IAP/水印/许可/促销（商业化永久非目标）
- 视频剪辑（时间线裁剪/拼接/多轨）——P9 只做缩放分段编辑与导出参数调整
- 摄像头虚拟背景的自定义图片导入（只用内置几种，见 P5 规格）
- Windows/Linux、App Store 分发
- 键盘可视化的自定义皮肤包（只给颜色/字号/停留时长/位置参数）

### 反目标（出现即失败，继承一期并新增）

- 继承一期全部反目标：音画同步 >100ms；长录内存无限增长；暂停时间线错乱；需要驱动
- **新增**：开启缩放/标记/键盘可视化/虚拟背景任一效果后，60fps 录制出现可感知掉帧或 CPU/GPU 占用失控（Apple Silicon 基准：效果全开时长录仍须平稳）
- **新增**：效果叠加的合成次序出现视觉错乱（见 §5 合成次序总则）

## 3. 约束（继承一期，标注变化）

- **最低系统 macOS 13 不变**。二期所用 API 均在 13 可用：`VNGeneratePersonSegmentationRequest`（12+）、`SMAppService`（13+）、`SCContentFilter(desktopIndependentWindows:)`（12.3+，一期已验证 SDK 27 头文件在）
- **非沙盒、LSUIElement、Developer ID 直分发不变**
- **零新 TCC 红线：保留一项经用户批准的例外**——P4 键盘可视化需要「输入监控」（Input Monitoring）权限。这是用户 2026-10-30 明确纳入范围的决定；除此之外不得引入任何新权限。P4 的引导 UI 沿用一期权限引导窗模式
- 既有纪律不变：274 测试全绿零告警、headless 可测缝（纯函数 + 时钟/依赖注入）、xcodegen 管理工程（新增文件后 generate）、零告警构建、macOS 13 底线、UI 简体中文为主
- 文件命名、输出目录、MP4/H.264(默认)/HEVC/AAC 均沿用一期

## 4. 既有架构接缝（二期全部功能挂在这些缝上）

- `CaptureController` 状态机（idle/countdown/recording/paused/finishing）与 `CaptureMode`（fullscreen/window/region）
- 视频热路径：SCStream → 暂停平移 → 合成器（PiP + 点击高亮）→ append；**全关时合成器为 nil**（任何常开效果都会让合成器常在，性能预算见反目标）
- `SystemAudioMixer`：系统声+麦混音，live setMicMuted/setMicVolume
- `ClickHighlightTracker`：NSEvent 全局+本地鼠标监听（record-only），`evaluate()` 纯 alpha 源
- `RegionSelector.selectRegion`（鼠标所在屏遮罩拖框）；`WindowPicker`/`WindowPickerView`/`WindowTargetResolver`；`SettingsStore`（@Published+UserDefaults+钉测模式）；`RecordingFileStore`；MenuBarExtra 状态图标；`FloatingControlBarPanel`；QuitGuard；UNUserNotificationCenter

## 5. 分功能规格（微决策已钉定，标注「本文档代定」）

### P1a 点击自动缩放

- **行为**：偏好开关（默认关）+ 缩放档位三选（1.35x/1.6x 默认/1.9x）。录制中在**采集画面内**点击 → 以点击点为中心放大至档位，保持 ~1s，缓出回原位 ~0.4s；连点以最新点击重定中心（进入新攻击段）；暂停时不触发；与点击高亮并存（环照画）
- **实现锚点**：`AutoZoomState` 纯逻辑（攻击/保持/回弹时间线，时钟注入，headless 钉测）；合成器在基础帧上施加仿射缩放（CI 变换），中心点钳制使放大窗口不越出画面；**缩放作用于「基础帧+内容锚定层」的合成结果，PiP 与键盘可视化在缩放后叠加（小窗/键帽尺寸与位置不受缩放影响）**
- **设置**：`autoZoomEnabled`（false）、`autoZoomLevel`（1.6）；偏好位置：录制源 Tab 点击高亮旁；开录快照语义（同 clickHighlightEnabled），录制中不改

### P1b 点击音效

- **行为**：独立偏好开关（默认关）。点击事件 → 混音器注入短促内置音效（bundle `mouse_click.wav`），音量固定合理值（不设滑杆）。**音效只进录制音轨，绝不做实时监听回放**（避免回授）
- **双源全关语义**（本文档代定）：音效开关开启时录制**必有音轨**——系统声/麦全关时建「效果专用音轨」（RecordingConfiguration 音轨存在条件改为 `captureSystemAudio || captureMicrophone || clickSoundEnabled`，mixer 相应常建），不做静默无效、不做偏好互斥
- **实现锚点**：复用 `ClickHighlightTracker` 事件源；mixer 加一路效果缓冲调度（AVAudioSourceNode/buffer schedule）；事件→调度抽缝 headless 钉测；注意与暂停语义一致（暂停期间不触发）

### P2 边录边标记

- **行为**：录制/暂停中可从浮条按钮或 `⇧⌘M` 开关标记工具条（nonactivating 面板，样式对齐浮条）。工具：**画笔**（两色可选+两档粗细）、撤销一笔、清空。笔画绘制在输出画面上并**烧入视频**（不存图层、不可后期编辑）；「暂停中可继续画，画的内容在恢复后可见」
- **输入面（独占绘图模式，本文档代定）**：标记模式开启时，App 在**每个被录显示器**上放置透明全屏覆盖面板接收鼠标拖拽（屏幕标注类工具的行业惯例：绘制期间鼠标被 App 截获，底层 App 收不到——工具条与面板本身照常交互）。拖拽映射为输出帧归一化笔画；**绘图拖拽不触发点击高亮/缩放/音效**（它们是笔画不是点击），非绘图状态（工具条开但未按笔/标记模式关）一切照常
- **合成次序（总则 v2，本文档代定，全项目一致，取代 v1）**：按锚定空间分两层——**内容锚定层**（标记笔画、点击环，存于底帧归一化空间）先画在基础帧上，**然后统一施加缩放变换**；**视口锚定层**（键盘可视化、PiP）在缩放后叠加。理由：批注随内容走（放大时圈住按钮、回弹后仍圈住按钮——教学语义正确），PiP 是讲师人脸盖在最终画面上，键帽属于输出 UI 不随内容缩放。P9 离线渲染复用同一「底帧+内容层 → 缩放」变换函数
- **坐标语义**：笔画与点击环存**底帧归一化坐标**（内容锚定）；绘制点经当前缩放变换**逆映射**到底帧空间（标记模式下若正在缩放中）；窗口/区域模式下若底帧坐标超出采集帧则裁掉（与点击环越界语义一致）
- **实现锚点**：`MarkingStroke` 模型（归一化点列、色、宽）+ `MarkingCanvas`（ObservableObject，undo/clear 纯逻辑可测）；工具条 UI 挂 `FloatingControlBarPanel` 同款面板机制；`⇧⌘M` 走 KeyboardShortcuts 新 Name（默认可改）
- **文字工具**：停放三期（范围控制）

### P3a App 内容录制

- **行为**：新 `CaptureMode.app(...)`：录某 App 当前全部窗口。入口：开始录制子菜单新增「App…」→ 选择器（复用 WindowPickerView 加 App 范围切换，列表列运行中 App：图标+名称+窗口数）；选中即录；App 退出 → 走一期源丢失自动保存路径
- **画布纪律（本文档代定，延续一期「开录锁定」）**：窗口集合**开录时固定**——录制中新开窗口不自动入画；部分窗口关闭继续录（剩余窗口照常），**全部关闭**才走源丢失自动保存；不引入中途流重配置机制
- **实现锚点**：`SCContentFilter(desktopIndependentWindows:)` 按 NSRunningApplication 过滤；模式持久化沿用 last-used-mode

### P3b 窗口区域录制

- **行为**：入口「窗口区域…」→ 窗口选择器 → 选中后**窗口内拖框**（RegionSelector 改造：遮罩锚定目标窗口 frame，输出窗口相对 rect）→ 录制该窗口的子矩形；窗口移动时子区域跟随窗口（filter 锚窗口 + sourceRect 裁剪，裁剪坐标为窗口相对系——**不经过 F3 的全局坐标坑**）
- **画布纪律**：子矩形**开录时对窗口边界钳制固定**；录制中窗口缩小时的呈现沿用一期窗口模式的既有实测语义（不做中途重配置、不 letterbox 新策略）
- **实现锚点**：`CaptureMode.windowRegion(...)`；窗口相对 rect 直入 SCStreamConfiguration.sourceRect（在 window filter 输出上裁剪）

### P4 键盘按键可视化

- **行为**：偏好开关（默认关）+ 样式参数（颜色单选、字号三档、停留时长 1/2/3s、位置底部居中）。开启时 App 请求「输入监控」权限（引导 UI 沿一期模式）；录制中按键（含修饰键组合如 ⌘C）以键帽样式叠加在输出帧底部居中，停留后淡出；组合键期间持续显示，松开修饰键立即结算
- **IME/安全输入语义（本文档代定，行业惯例）**：键帽显示**原始按键**——拼音 IME 组合期显示原始字母（如 n-i-h-a-o），不上屏后字符，这是 NSEvent 数据源的固有能力边界，偏好页说明文案注明此限制；**安全输入**（任意 App 开启 Secure Event Input，如密码框）→ 全局监听静默跳过（不显示、不记录、不崩溃），偏好页注明「检测到安全输入时暂停显示」
- **实现锚点**：NSEvent 全局+本地键盘监听（`addGlobalMonitorForEventsMatchingMask: .keyDown` + 本地 monitor，Input Monitoring TCC 只影响全局监听——本地监听免权，语义与点击跟踪器对称）；`KeyboardOverlayState` 纯逻辑（组合键聚合/停留/淡出时间线，时钟注入 headless 钉测）；**合成注入**（非屏幕窗口）——三种录制模式下都正确入画；合成次序：**视口锚定层**（见 P2 总则 v2，与 PiP 同层）
- **权限红线**：全局监听在授权前静默降级（只录本地键或完全不叠加，不崩溃），引导窗补齐授权后自动生效

### P5 摄像头虚拟背景

- **行为**：偏好「摄像头背景」：原画面（默认）/ 模糊 / 内置背景（3 选：中性渐变 ×2、纯色 ×1——不内置照片素材，控制包体）。作用于 PiP 摄像头画面；开录快照语义
- **实现锚点**：`VNGeneratePersonSegmentationRequest`（qualityLevel 观感/性能权衡留给构建者，QoS 后台队列）→ CIImage mask → 前景合成背景层；挂摄像头 dataOutput → 合成器输入之前；效果关闭时代价为零（旁路）

### P6a 开机自启

- 偏好 通用 Tab 开关；`SMAppService.mainApp`（macOS 13+）register/unregister，失败以通知提示（不弹窗）

### P6b 定时录制

- **行为**：菜单「定时录制…」→ 面板：开始时刻（指定时间 / N 分钟后）+ 可选时长上限（到点自动停止保存）。触发前菜单栏图标显示倒计时态；触发时按 last-used 模式起录（倒计时叠加可选，默认不加）；可取消
- **错过调度契约（本文档代定）**：**不唤醒 Mac**（不做电源唤醒调度——深夜唤醒用户机器属惊吓行为）。到点时：机器醒着且未锁屏 → 正常触发；正在录制/收尾 → 跳过+通知；锁屏 → 跳过+通知（冷启动录制不做锁屏语义，一期「锁屏继续录」只适用于已开录的场次）；机器睡眠错过 → 唤醒后补一条带「开始录制」动作按钮的通知（不自动起录）
- **实现锚点**：调度逻辑抽缝（注入 Date/Timer，headless 钉测：到点触发/取消/时长上限自动停止/错过补通知四条路径）

### P7 声音录制 / 摄像头录制独立模式

- **声音录制**：菜单入口 → 只录系统声+麦 → 输出 `.m4a`（AVAssetWriter 纯音轨；浮条照常、无画面预览；文件列表兼容（扩展名过滤放宽 m4a）；暂停/快捷键/通知全兼容
- **摄像头录制**：菜单入口 → 只录摄像头+麦 → 常规 MP4 单画面；PiP/缩放/标记在此模式下不可用（入口置灰）
- **实现锚点**：`CaptureMode.audioOnly` / `.cameraOnly`；文件列表过滤从「.mp4」放宽为「.mp4|.m4a」（P7 完成时同步改测试矩阵）；QuickLook 原生可播 m4a

### P8 GIF 导出 + 转换压缩

- **行为**：文件列表行操作新增「导出 GIF…」（参数：帧率 5/10/15、宽度 480/720/原宽、循环默认无限）与「压缩…」（HEVC 更低码率重封装/重编码预设）。进度以模态小窗展示；输出落源文件同目录
- **实现锚点**：GIF：AVAssetImageGenerator 抽帧 + CGImageDestination（纯函数核心 headless 可测：给定抽帧序列→GIF 数据）；压缩：AVAssetExportSession 预设。两者都是**离线批处理**，不进录制热路径

### P9 视频编辑器（缩放分段剪辑导出）

- **行为**：文件列表行操作「编辑…」→ 时间线窗口：预览播放器 + 缩放分段列表（入点/出点/档位/中心点）；导出 MP4（帧率/分辨率/画质可调，预估大小）。**不做裁剪/拼接/多轨**
- **实现锚点**：离线渲染管线——**复用 P1a 的缩放变换代码**（同一变换函数，实时与离线两个调用方）；分段数据模型 Codable 可持久化（草稿保存）；AVAssetReader 逐帧 → 变换 → AVAssetWriter；导出进度通知 UI
- 这是二期最大件，计划阶段允许多任务拆分

## 6. 交付与验收

- 每批一个 SDD 批次（实现 → 双裁审 → 修复轮 → 真机验收清单）；批次间可暂停
- 真机验收重点：P1 效果叠加下的 60fps 长录平稳性（反目标）；P4 权限引导与授权前降级；P5 观感（人像边缘）；P9 离线导出的时长正确性
- 每批交付时 README 功能清单同步更新（中英两份）
