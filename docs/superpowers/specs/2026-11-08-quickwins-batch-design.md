## 1. 意图与背景

Omi 对照盘点（2026-11-08）确认功能矩阵主体已对齐；剩余缺口分四组。本批取「小件速赢」组六件——全部为 Omi 已验证存在、本库代码实证缺失、工程量小且互不依赖的功能，一次批次打包交付。目的：把日常使用里「缺了会烦」的小缝一次补平。

## 2. 目标 / 非目标 / 反目标

### 目标（本批六件，Q1–Q6 编号）

| 件 | 功能 | 一句话 |
|---|---|---|
| Q1 | 截图 | 区域拖框 / 整屏两种截图，PNG 落输出目录 + 通知 |
| Q2 | 鼠标光标显示开关 | 偏好开关控制录屏是否带鼠标指针（开录快照） |
| Q3 | 重新录制 | 录制/暂停中一键丢弃已录内容并立即重开同模式（两击确认） |
| Q4 | 移出列表 | 文件列表条目移出（文件原地保留），持久化记账 |
| Q5 | 长录时长提醒 | 净录时长每跨 N 小时整数倍提醒一次（1/2/3h/从不） |
| Q6 | 编辑后动作 | 编辑器导出完成后可自动「打开所在目录」/「删除原始文件」 |

### 非目标（本批不做）

- 每模式独立快捷键、键盘可视化增强参数（仅组合键/换行延迟/淡出时长/预览）、引导教程页——② 组中件，后续批次候选
- 文字标注工具、虚拟背景自定义图片、分段恢复——继续停放（一期/二期既定）
- 截图入文件列表、窗口截图、截图倒计时、截图快捷键
- Q3 的快捷键入口（快捷键面归统一批次做，本批只做浮条+菜单）
- GIF/压缩导出（P8）追加编辑后动作——仅编辑器（P9）导出挂钩

### 反目标（出现即失败）

- 继承全部既有反目标（音画同步/内存/暂停时间线/性能/合成次序）
- **Q6 在任何校验不通过场景误删原始文件**（本批最大风险项，见 §3 安全纪律）
- **Q4 丢失用户文件**——移出只许记账（UserDefaults 集合），绝不触碰文件系统
- **Q3 把上一场内容意外落盘**——丢弃语义必须与既有丢弃路径完全一致，不得先落盘再删

## 3. 分件规格（微决策已钉定，标注「本文档代定」）

### Q1 截图

- **入口**：菜单栏「截图」子菜单：「区域截图…」「全屏截图 →（显示器列表，主屏追加「（主）」——沿用显示器菜单既有命名）」。仅空闲态可用；倒计时/录制/暂停/收尾中菜单项**置灰**（沿用既有 disabled 模式，同「开始录制」项）
- **区域截图**：点选 → 复用 `RegionSelector.selectRegion(on:)` 拖框（Esc 取消 = 静默无输出）→ 取该显示器整帧位图、按像素坐标裁剪该 rect（坐标系与区域录制同一套换算）→ PNG 落输出目录
- **全屏截图**：整屏位图整存（保留 HiDPI 原生像素尺寸）
- **命名与输出**：`截图_yyyy-MM-dd_HH-mm-ss.png`，冲突追加 " (2)"（复用 `nextFileURL` 语义，扩展名参数既有）；落盘后系统通知「截图已保存：<文件名>」（尽力而为副通道，同 post 纪律，被拒静默）；**不入文件列表**（列表语义保持「成片 mp4/m4a」；Omi 列表类型栏亦无图片类型证据）
- **实现锚点**：捕获用 `CGDisplayCreateImage`（部署目标 13 < 弃用版本 14，零告警纪律不受影响；不引 macOS 14+ 的 SCScreenshotManager）；位图→裁剪→PNG data 抽纯函数缝 headless 钉测（给定 CGImage/rect → 裁剪像素尺寸正确、PNG data 非空可解）；显示器枚举/主屏判定复用既有菜单数据源；**失败语义**（本文档代定）：捕获/裁剪/写盘失败静默 + NSLog（成功才通知——尽力而为副通道纪律的对称面）；**捕获时机**：区域选择覆盖层摘除落定后再取帧（防遮罩污染位图，工程防御，归构建者）

### Q2 鼠标光标显示开关

- **行为**：偏好「录制源」Tab 新开关「录制鼠标光标」（默认**开** = 显示，保持现状语义）。**开录快照**语义（同 clickHighlightEnabled：录制中改偏好不影响本场，下一场生效）
- **作用域**：全部 SCStream 画面模式（全屏/窗口/区域/App/窗口区域）；仅摄像头/仅声音模式无此语义
- **实现锚点**：`SCStreamConfiguration.showsCursor`（本机 SDK 实证存在、默认 true）在 `SCStreamRecorder` 构建配置处接线；`SettingsStore` 加 `@Published` + UserDefaults 持久化 + 钉测（既有模式纪律）

### Q3 重新录制

- **入口**：浮条新按钮（录制/暂停中可见，紧邻丢弃——语义近亲）+ 菜单栏「重新录制」；本批不做快捷键
- **行为**：第一次点击 → 武装态（红底胶囊白字「再次点击确认重录」，视觉/纪律同丢弃，disarm 窗口 5s）→ 第二次点击 → **丢弃已录内容（不落盘）** + **立即**以当前场次相同模式 + 相同配置重新开录，**绕过倒计时**（复用 `bypassCountdown` 缝；用户意图明确 = 立刻重来，倒计时属打扰。本文档代定）
- **状态边界**：仅 recording/paused 可用；倒计时/收尾中不可用；重开失败（如源已丢失）走既有起录失败路径，不重试不循环
- **实现锚点**：`DiscardConfirmation` 泛化复用（武装逻辑同构，文案参数化——实现计划定具体形状）；装配层 `restartRecording()`：既有丢弃路径完成后调 `startRecording(bypassCountdown: true)`；丢弃→重开之间的 finishing 瞬态不新增浮条状态。**配置语义**（本文档代定）：重录走装配层既有起录入口 = **新一轮设置快照**（与手动起录完全一致），非逐字复用上一场运行时配置。**定时场边角**（本文档代定）：定时场次中手动重录 → 调度器停录等待沿用既有存活闩重估语义（心跳未落在丢弃瞬态时剩余时长上限延续到重录场；落在瞬态则上限解除），本批不为此引入新调度机制。浮条按钮经装配层接线（既有 attachMarkingToggle 先例）；丢弃完成检测需控制器小缝（形状归计划阶段）

### Q4 移出列表

- **行为**：文件列表行右键新增「移出列表」：条目从列表消失，**文件原地保留**；无恢复入口（打开输出目录即见原文件；重开列表不回来）
- **实现**（本文档代定）：持久化「已移出」绝对路径集合（UserDefaults，键 `removedFromListPaths`）；`contents()` 层过滤——**列表 = 目录扫描 ∩ 成片扩展名 − 已移出集合**（单点语义）；集合自愈：过滤时顺手剔除已不存在的路径（文件被外部删除则其集合项失去意义，防集合无限增长）
- **边界语义**（本文档代定，按绝对路径记账的固有性质，接受）：文件重命名/移动后路径不再命中集合 → 会重新出现在列表（可再次移出）；「删除」操作不经过集合（真删文件）
- **实现锚点**：`RecordingFileStore.contents()` 加排除集注入缝；headless 钉测：移出→不含；外部删除→集合自愈；重命名→重新出现；集合读写不抛错

### Q5 长录时长提醒

- **行为**：偏好「通用」Tab「录制提醒间隔」四档：**1 小时（默认）/ 2 小时 / 3 小时 / 从不**。净录时长（`controller.elapsed`，暂停排除、与浮条同一真源）每跨过间隔整数倍 → 系统通知一条「已录制 N 小时，请注意磁盘剩余容量」；同一场次每整倍恰一条（1h 档、2.5h 场次 → 1h、2h 各一条）。**作用域**（本文档代定）：全部录制模式统一适用（elapsed 模式无关；仅声音/仅摄像头的长录同样需要磁盘提醒）
- **实现锚点**：阈值跨界纯函数（elapsed 序列 + interval → 应提醒的小时数，headless 钉测：恰跨/整倍/暂停排除/改档只对下一场生效——间隔开录快照语义）；挂 `CaptureController` 既有 elapsed timer 更新点；通知走 `UNRecordingNotifier` 新方法（`notifyRecordingDurationReached(hours:)`，尽力而为副通道）

### Q6 编辑后动作

- **行为**：偏好「通用」Tab「编辑导出完成后」组两开关：「打开文件所在目录」（默认关）、「删除原始文件」（默认关）。作用域**仅缩放分段编辑器（P9）导出**（对齐 Omi EditStopped 语义）
- **安全纪律（反目标级，逐条钉死）**：「删除原始文件」仅在导出**成功** 且 输出文件**存在** 且 **字节数 > 0** 三项校验全过时执行；任一不满足 → 不删、走既有失败路径。删除完成后通知正文注明「原始文件已删除」（用户知情权）
- **顺序语义**（本文档代定）：两开关同开时先 reveal 新成片、后删原始文件（Finder 焦点不被删除动作抢走；reveal 的永远是新成片）。删除原始文件时**同步删除其缩放分段草稿**（`<成片>.zoomdraft.json`）——草稿随源亡（既有删除路径先例），不留孤儿 JSON
- **实现锚点**：编辑器导出完成回调（装配层 `ExportNotifying` 接线处）读偏好执行；动作序列抽缝 headless 钉测（给定导出结果 + 偏好 → 动作序列 [reveal/delete]，删除仅在成功+存在+非空时发生）；reveal = `NSWorkspace.activateFileViewerSelecting`

## 4. 约束（继承，无变化）

- **macOS 13 底线**：本批全部 API 在 13 可用（`showsCursor` 12+、`CGDisplayCreateImage` 久远 + 14 起弃用但部署目标 13 无告警、`NSWorkspace` 久远）
- 非沙盒、LSUIElement、Developer ID 直分发不变；**零新 TCC**（截图复用屏幕录制既有授权）
- 纪律不变：测试全绿零告警、headless 可测缝（纯函数 + 时钟/依赖注入）、xcodegen 管工程（新增文件后 generate）、UI 简体中文、每件 README 功能清单同步（中英）
- 文件命名风格延续：`截图_` 前缀与 `录屏_` 对称；输出目录沿用
