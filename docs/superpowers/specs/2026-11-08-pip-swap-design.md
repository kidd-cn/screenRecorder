## 1. 意图与背景

录制中临时对调画面主次：摄像头放大成主画面、屏幕缩成小图，**写进成片**，从切换那一刻起布局跟着变。用户原话钉定：「录制中临时切换就行，摄像头放大成主画面、屏幕缩成小图」「写进成片，切换那一刻起布局就跟着变」。摄像头铺满方式经视觉对比选定 **B 方案 = contain（完整放入，绝不裁脸）**；入口经选项单选钉定**仅浮条按钮**。

工程可行性已核实（brainstorming 阶段读码确认）：`PiPCompositor.composite` 逐帧消费「底帧 + 摄像头帧 + 摆放 rect」，画布尺寸钉死在开录时刻（writer 不重配置）——对调是同一画布上的逐帧布局参数切换，不中断录制。

## 2. 目标 / 非目标 / 反目标

### 目标

- 浮条新按钮 ⇄（SF Symbol 风格，标记之后、暂停之前），**仅录制中且本场启用摄像头画中画时出现**；一键对调/换回，来回不限
- 对调后成片布局：摄像头 contain 放入画布（比例不合处纯黑边、绝不裁脸）+ 屏幕层缩成 160×120 圆角小图（默认锚点同今日摄像头浮窗 `PiPLacementAnchor.defaultFrame`），可拖动、成片实时跟随
- 切换为逐帧参数级：录制不断、画布尺寸不变、PTS 连续
- 每场开始复位「屏幕为主」；不持久化（用户：「临时切换就行」）

### 非目标

- 快捷键（归统一批次）、菜单栏入口（用户未选）、小窗双击切换（与拖动手势冲突，明确不做）
- 持久化「摄像头为主」偏好
- 仅摄像头模式的对调语义（无屏幕层，按钮不出现）
- 画布尺寸/分辨率随对调变化（恒为开录时刻屏幕捕获尺寸）

### 反目标（出现即失败）

- **对调导致录制中断、丢帧、writer 重开或 PTS 跳变**（切换必须是平滑的逐帧参数变化）
- **摄像头画面被裁剪**（contain 铁律——与现有 placePip 的 aspect-fill 只作用于小图，不适用于主画面）
- 对调后成片分辨率/时间轴与切换前不一致

## 3. 行为规格（微决策已钉定，标「我定」）

### 3.1 切换语义

- 会话级布尔 `layoutSwapped`（false = 屏幕为主）。主线程写、video 队列逐帧读——锁保护快照纪律（`PiPFrameStore` 同款）。
- 按钮出现条件：`state ∈ {recording, paused}` 且本场摄像头画中画启用。暂停中允许对调（暂停段本不入成片，恢复后体现新布局）。
- 文案：tooltip/accessibility「对调画面（摄像头为主）」↔「换回屏幕为主」。
- 按钮视觉恒为 ⇄，**不做高亮/武装态**（我定——当前布局靠成片与浮窗所见即知，不再加一个状态视觉）。

### 3.2 对调后布局（合成规格）

- 画布：开录时刻捕获像素尺寸，不变。
- 摄像头主画面：contain——缩放比取宽高比**小者**，居中，余处纯黑（黑边底色纯黑，我定）。
- 摄像头朝向恒定（我定，构建者核查裁决）：对调态主画面**不镜像**，与既有成片「他人视角」语义一致（P7b 钉定；镜像属预览窗特权，不入成片）。切换前后同一颗摄像头朝向绝不翻转；P5 虚拟背景段同此（不新增镜像步骤）。
- 屏幕小图：160×120 语义 rect（圆角 12，同今日浮窗约定），屏幕内容 aspect-fill 进小图（与现有 placePip 摄像头填充同语义）；浮窗拖动实时进 `PiPFrameStore` 同一换算链（`PiPCaptureGeometry` 复用）。
- 特效共存（我定，按既有「内容锚定/视口锚定」分类法）：
  - **内容锚定**（点击高亮、标记笔画、缩放变换）：施加于屏幕层——缩进小图**之前**，随小图等比缩小，成片观感「效果发生在屏幕小图内」
  - **视口锚定**（键帽）：画布底部居中，不受对调影响
  - 对调态合成次序：黑边画布 + 摄像头（contain）→ 屏幕层（含环/笔画/缩放）等比贴入小图圆角 → 键帽
- 换回 = 状态翻回，布局即回「屏幕为主 + 摄像头小图」，与今日行为逐帧一致。

### 3.3 浮窗对调态行为（2026-11-11 修订：成片缩影）

- 窗内预览切换为**成片缩影**（我定，2026-11-11 用户拍板；取代 2026-11-08 钉定的「屏幕内容缩略图」——真机验收撞上盲区：原设计现场无摄像头主画面表达，脸从浮窗消失且无处可看）：完整对调布局的实时缩略预览——黑底画布 + 摄像头 contain 主画面 + 屏幕小图按真实相对位置同位呈现，窗内 aspect-fit **完整可见**（含黑边）。整窗所见即整片所得。
- 缩影渲染语义：按**成片**渲染——摄像头不镜像（镜像属预览特权）、小图直角圆角同成片；小图特效（点击环/笔画瞬态）与键帽**不入缩影**（我定：瞬态/视口内容经 0.5s 采样会失真频闪，缩影表达的是布局不是特效）。
- 拖动语义不变：整窗拖动 → 屏幕小图位置；窗内小图角标即其当前相对位置（拖动后 ≤0.5s 跟随）。换回后恢复摄像头预览。
- 数据源（构建者核查项结论，维持）：录制器逐帧缝低频分路（≤0.5s 节流），对调态在视频队列合成缩影；摄像头缺帧（断源窗口期）缩影诚实呈现黑主画面 + 小图，与成片一致。

### 3.4 边界

- 无摄像头场次 / 仅摄像头模式：按钮不出现。
- 摄像头中途断源（用户裁决 2026-11-08，选 (a) 会话级失败）：检测到摄像头断开 → 走与屏幕丢源相同的失败收场（停录 + 自动保存 + 通知）。**本批新增摄像头断源检测**——核查证实既有代码无此路径（`latestPixelBuffer` 恒持最后帧 → 今日实为静默冻结），本检测顺带修掉该瑕疵；检测作用于「本场启用摄像头画中画」的任意布局态（对调与否同一条检测链）。检测生效前后的极短窗口内成片持最后帧属检测延迟，非设计冻结；检测生效即收场，不长期冻结假画面。
- 音频、计时、暂停、磁盘监控：完全不受对调影响。

## 5. 交付与验收

- headless 钉测清单：对调布局纯函数（16:9 摄像头进 16:10 画布 → 黑边数值；4:3 进 16:9；同比例零黑边）；屏幕小图 rect 换算（含拖动跟随）；对调态合成次序（屏幕层在键帽之下、小图圆角在位）；按钮可见条件（recording/paused × 摄像头启用矩阵）；摄像头断源 → 会话失败路径触发（接线钉测）
- 真机验收：录制中对调→成片前段屏幕主、后段摄像头主，无缝无跳帧；contain 绝不裁脸；拖动小图成片实时跟随；特效在小图内生效；暂停中对调恢复后生效；换回后浮窗恢复摄像头预览；**对调态浮窗显示成片缩影（摄像头主画面可见、小图角标同位、拖动 ≤0.5s 跟随、aspect-fit 完整可见）**；来回切换多次无内存增长；录制中拔摄像头 → 自动保存收场 + 通知（对调态与常规态各验一次）
